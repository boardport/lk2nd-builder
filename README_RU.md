Модульный сборщик модифицированных образов загрузчиков lk2nd и lk1st на основе внешних оверлеев для встраиваемых плат, 4G/LTE-модемов и мобильных устройств.

Репозиторий входит в экосистему **[BoardPort](https://github.com/boardport)** и предоставляет чистый слой адаптации
поверх штатной сборочной среды lk2nd без отслеживания тяжелых кодовых баз апстрима и засорения базовых исходников.

> 🤖 **Примечание для AI-ассистентов:** Автономные агенты и LLM-ассистенты обязаны ознакомиться с правилами проекта
> в файле [AGENTS_RU.md](./AGENTS_RU.md) перед началом работы в этом репозитории.

---

## 🎯 О проекте

Главная миссия **lk2nd Builder** — оркестрация воспроизводимой контейнеризированной сборки модифицированных образов `lk2nd` и `lk1st`,
сконфигурированных с учетом аппаратных особенностей различных встраиваемых платформ:

- 📶 **Сотовые 4G/LTE USB-модемы и компактные роутеры:** мобильные шлюзы, USB-донглы и платформы на базе Qualcomm MSM.
- 🧩 **Платы разработки и одноплатные компьютеры (SBC):** отладочные комплекты и вычислительные модули.
- 📱 **Вторичное использование мобильных устройств:** смартфоны и планшеты, переводимые на запуск mainline Linux.

### Архитектура репозитория

Проект организован как модульный оркестратор, координирующий изолированные подмодули:

- **`docker/` ([lk2nd-docker](https://github.com/boardport/lk2nd-docker)):** Многостадийные рецепты сборки контейнеров,
  предоставляющие изолированный тулбокс и кросс-компиляторы (`arm-none-eabi-`, `aarch64-linux-gnu-` и др.).
- **`overlay/` ([lk2nd-overlay](https://github.com/boardport/lk2nd-overlay)):** Внешний аппаратно-зависимый оверлей с деревьями устройств (DTS),
  платформенными таргетами и патчами.

## ⚡ Быстрый старт

Репозиторий включает инструментарий автоматизации на базе Make:

### 1. Просмотр доступных команд

```bash
make help
make list
```

### 2. Инициализация подмодулей

Убедитесь, что все git submodules инициализированы и подгружены:

```bash
git submodule update --init --recursive
```
