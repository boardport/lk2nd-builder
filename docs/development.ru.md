# 🛠️ Руководство по разработке и сборке: BoardPort — lk2nd Builder

Практическое руководство разработчика по работе с контейнерным окружением, целями Make,
параметрами конфигурации сборки и интерактивной отладкой.

---

## 📋 Предварительные требования

Для локальной сборки загрузчиков в проекте **BoardPort — lk2nd Builder** требуются:

- **Git:** с поддержкой подмодулей (`git submodule update --init --recursive`)
- **Среда контейнеризации:** Docker Engine (v20.10+) или Podman
- **GNU Make:** стандартная утилита автоматизации

---

## ⚡ Автоматизация и сценарии сборки (Make)

Репозиторий включает набор автоматизированных сценариев Make, оборачивающих сборку OCI-контейнеров:

### 1. Просмотр доступных целей

Вывод списка поддерживаемых команд автоматизации со справкой:

```bash
make help
make list
```

### 2. Инициализация подмодулей

Перед началом локальной сборки загрузите все вложенные Git-субмодули:

```bash
git submodule update --init --recursive
```

### 3. Сборка базового контейнера Toolbox

Сборка базового Debian-образа со всеми системными утилитами и кросс-компиляторами:

```bash
make lk2nd-build-toolbox
```

### 4. Сборка окружения Toolchain с апстримом lk2nd

Клонирование исходного кода `lk2nd` в изолированный слой контейнера для заданной ветки или тега:

```bash
# Сборка ветки разработки по умолчанию (main)
make lk2nd-build-toolchain LK2ND_REF=main

# Сборка фиксированного тега релиза (например, 23.1)
make lk2nd-build-toolchain LK2ND_REF=23.1
```

### 5. Сборка образа Target с интегрированным оверлеем

Внедрение аппаратно-зависимого оверлея непосредственно в образ для автономной офлайн-сборки:

```bash
make lk2nd-build-target LK2ND_REF=23.1 OVERLAY_REF=23.1
```

### 6. Компиляция образов загрузчика

Запуск компиляции целевого профиля внутри контейнера с наложением внешнего оверлея:

```bash
# Компиляция целевого профиля для релиза 23.1
make lk2nd-build LK2ND_REF=23.1 LK2ND_TARGET=lk2nd-msm8916-boardport
```

Готовые бинарные артефакты сохраняются в каталог `docker/volumes/output/`:

- `lk2nd.img` — образ загрузчика формата Android boot image для fastboot boot или прошивки в recovery.
- `emmc_appsboot.mbn` — полезная нагрузка первичного загрузчика для прошивки в raw-раздел aboot или EDL.
- `qcdt.img` — бинарная таблица деревьев устройств Qualcomm (QCDT), добавляемая к boot-образам.
- `lk.bin` — чистый исполняемый бинарный файл Little Kernel.

### 7. Интерактивная отладка в контейнере

Запуск интерактивной командной строки внутри контейнера toolchain с подмонтированным оверлеем:

```bash
make lk2nd-sh-toolchain LK2ND_REF=23.1
```

## ⚙️ Переменные конфигурации

Система сборки принимает параметры через переменные окружения или флаги командной строки:

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `LK2ND_REF` | `main` | Git-ссылка (ветка или тег) апстрима `msm8916-mainline/lk2nd` |
| `LK2ND_COMMIT` | *(пусто)* | Опциональный точный хэш коммита апстрима lk2nd |
| `OVERLAY_REF` | `main` | Тег релиза или ветка `lk2nd-overlay` для интеграции в Target |
| `LK2ND_TARGET` | `lk2nd-msm8916-boardport` | Профиль целевой сборки из `overlay/project/` |
| `CONTAINER_TOOL` | `docker` | Среда выполнения контейнеров (`docker` или `podman`) |
