# 📖 Project Overview: BoardPort — lk2nd Builder

High-level overview covering the project mission, supported hardware platforms,
ecosystem decomposition, and bootloader binary outputs of **BoardPort — lk2nd Builder**.

---

## 🎯 Mission and Philosophy

The primary mission of **lk2nd Builder** is orchestrating containerized and reproducible builds of modified `lk2nd` and `lk1st`
bootloader images tailored to hardware-specific constraints across diverse embedded platforms:

- 📶 **Cellular 4G/LTE USB Modems and Portable Routers:** Compact mobile gateways, USB dongles, and Qualcomm MSM-based hardware
  (such as MSM8916 stick routers, UFI001C, UFI103S, QRCT, and related derivatives).
- 🧩 **Development Single-Board Computers (SBCs):** Evaluation kits and computing modules requiring custom device trees,
  UART console routing, or modified memory layouts.
- 📱 **Repurposed Mobile & Embedded Platforms:** Converted smartphones and boards transitioning into headless mainline Linux appliances.

---

## 🌐 Ecosystem Role & Decomposition

This repository serves as the root build coordinator within the [BoardPort](https://github.com/boardport) ecosystem.
It isolates customization logic into an external overlay without tracking upstream trees or polluting baseline sources:

- **`docker/` ([lk2nd-docker](https://github.com/boardport/lk2nd-docker)):** Multi-stage container recipes providing isolated compilation
  toolboxes and cross-toolchains (`arm-none-eabi-`, `aarch64-linux-gnu-`).
- **`overlay/` ([lk2nd-overlay](https://github.com/boardport/lk2nd-overlay)):** Out-of-tree hardware overlay containing device trees (DTS),
  project target definitions, and proprietary board customizations.

---

## 📦 Bootloader Image Formats

Build outputs generated by lk2nd Builder serve different installation and flashing requirements:

- `lk2nd.img` — Android boot image format bootloader for fastboot booting (`fastboot boot lk2nd.img`) or recovery partition flashing.
- `emmc_appsboot.mbn` — Primary bootloader payload for raw partition flashing or EDL emergency recovery.
- `qcdt.img` — Qualcomm device tree table (QCDT) appended to boot images.
- `lk.bin` — Raw Little Kernel executable binary.
